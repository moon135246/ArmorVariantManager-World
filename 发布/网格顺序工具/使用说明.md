# 从 Blender 生成列表顺序

打开导出当前 MOD3 的原 Blender 工程，在 Python 控制台执行下列命令。把 SCRIPT 换成本目录“导出网格顺序.py”的完整路径，把 GAME_ROOT 换成安装该 MOD 的游戏根目录；路径可使用正斜杠。

```python
SCRIPT = 'D:/你的目录/网格顺序工具/导出网格顺序.py'
exec(compile(open(SCRIPT, encoding='utf-8').read(), SCRIPT, 'exec'))
export_current_scene('F:/SteamLibrary/steamapps/common/Monster Hunter World')
```

工具只读当前场景和 MOD3，生成同目录、同文件名的 `.meshorder`，不会重新导出模型或保存 Blender 工程。下次启动游戏时由管理器读取。列表按对象名称中的数字排序，例如 Sub_9 在 Sub_20 前；同一 Sub 编号继续按完整对象名排序。

场景需要保留导出器使用的 `f_arm105_0000.mod3` 等模型集合；网格对象名的 `__` 后部分须对应导出的材质名。材质对应不唯一且无法由完整集合顺序确定时，工具会报告错误，需要先核对模型，不能猜测网格对应关系。未包含在场景中的其他模型不会生成顺序表。

向其他装备编号发布同款 MOD 时，须为实际目标 MOD3 生成同名顺序表。重新导出导致网格表或材质表变化后，应重新生成顺序表。仅删除顺序表即可恢复按导出文件的网格表顺序显示；CFG 和 WDP 中的显隐目标不受影响。

分享 MOD 时把 `.meshorder` 与对应 MOD3 一起打包即可，接收者需要差分管理器 1.1.4 或更新版本。顺序表不包含个人预设或配置。
