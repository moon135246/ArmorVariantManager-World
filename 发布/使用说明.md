# 差分管理器 · 世界内置版 1.0.7

插件随游戏启动，F9 打开或关闭面板，无需连接游戏。1.0.7 新增“变身与条件”：根据猎人状态临时切换分组预设，条件退出后恢复基础状态，变身过程不会改写默认预设。

## 安装与升级

需要已安装 Stracker's Loader。先退出游戏，将发布目录的 `nativePC` 合并到游戏根目录，替换 `nativePC/plugins/WorldDiff.dll`。也可以运行“安装到游戏.cmd”；默认目录为 `F:\SteamLibrary\steamapps\common\Monster Hunter World`，自定义目录可传给 PowerShell 脚本的 `-GamePath` 参数。脚本会备份旧 DLL 和配置目录。

1.0.7 使用 `nativePC/plugins/WorldDiff/WorldDiff107.cfg`。首次启动没有该文件时，依次尝试读取 `WorldDiff104.cfg`、`WorldDiff103.cfg`，迁移分组、预设、默认项和设置；旧配置保留。不要同时运行旧版外置管理器。

1.0.7 可以读取旧 `.wdp`。新保存的文件采用 107 格式，包含变身规则，1.0.4–1.0.6 无法读取；回退旧插件时，应同时还原升级前的 `.wdp` 备份。仅替换 DLL 不会把新配置转换回旧格式。

## 界面与输入

- 部位与材质、变身与条件、设置与说明使用相同样式，当前页面以青色高亮描边区分。
- 默认按子网格顺序显示；“按子网格”在前，“按材质”在后。子网格名称后不再显示 `#0`、`#1` 等编号，材质悬停时不再弹出技术信息框。
- 分组、预设和部位筛选保留圆角高亮。分组和预设列表可拖动排序；右上角拖动提示点击 x 后永久隐藏。
- 在正常游戏场景按 F9 即可自由移动鼠标和拖动面板，无需先打开 Esc 菜单。
- 点击名称或搜索框后可使用系统输入法输入中文，也可粘贴。回车完成编辑，Esc 放弃本次输入；完成后再点击对应保存按钮。
- 关闭面板后规则继续生效，游戏恢复接收鼠标与键盘输入。Ctrl+F9 可暂停全部差分控制并恢复游戏显隐，已保存预设仍保留。

## 分组与基础预设

普通分组独占材质，主列表管理未划入普通组的材质。全局分组可与其他组重叠，最后叠加隐藏。

先在右侧调整显隐，再输入名称并保存预设。每个组有独立默认项，游戏启动时载入默认项；“选择时自动设为默认”可关闭。“按子网格”可分别控制共享材质的网格，仍保留游戏原有的显隐判断。

## 变身使用步骤

以拔刀后隐藏头发、收刀后恢复为例：

1. 在“头发”分组保存“显示头发”和“隐藏头发”两个预设，选择“显示头发”作为基础状态。
2. 打开右侧“变身与条件”，点击“新建变身规则”。
3. 填写规则名称，条件选择“收刀与拔刀”→“拔刀”。
4. 目标分组选择“头发”，目标预设选择“隐藏头发”，点击“保存规则”。
5. 保持“启用变身”和规则自身的勾选开启。拔刀时临时应用隐藏预设；收刀后恢复基础状态。

一条规则选择一个条件，可通过“添加目标分组”同时切换多个组。不同分组可以同时响应不同规则。同一分组被多条命中规则控制时，优先级数字越小越优先；同优先级按规则列表顺序取第一条。全局分组继续叠加隐藏。

变身生效的预设会标记 `[变身]`。左侧的基础选择和默认项不会被自动改写；在变身期间手动选择其他基础预设后，条件退出会恢复到新的基础选择。当前组受变身控制时，右侧显隐编辑暂时禁用，可点击“暂停变身并编辑”调整基础方案。

### 可用条件

| 条件 | 可选状态 |
| --- | --- |
| 收刀与拔刀 | 收刀、拔刀，可限定武器 |
| 太刀练气 | 无刃、白刃、黄刃、红刃、白刃及以上、黄刃及以上 |
| 双刀状态 | 普通、鬼人化、鬼人强化；鬼人化与强化可以重叠，需按优先级处理 |
| 强化状态 | 太刀红刃或双刀鬼人强化；可选择强化中、未强化 |
| 猎人血量 | 自定义百分比区间、血量归零、四个常用区间，以及触发后保持；可限定武器 |
| 武器种类 | 当前装备的武器类型 |
| 动作 LMT | 自定义动作编号范围，可限定武器 |

条件读取本地猎人的状态。读取不到所需状态时，不触发该条件，使用基础预设。操虫棍和其他武器专属状态留待后续验证。

血量区间包含上限，下限是否包含由“不包含下限”控制。例如 `(25%, 50%]` 表示大于 25%、小于或等于 50%。

血量条件勾选“触发后保持”后，仅在正血量时触发；回血后仍保持变身。血量归零、切图、角色变化、换武器、关闭变身、重载配置或保存规则编辑时会复位。页面上的“复位保持状态”也可手动复位；若当前条件仍满足，下次判断会再次触发。

## 预设文件与跨装备识别

`nativePC/plugins/WorldDiff/Presets/*.wdp` 是可分享的文件，包含一套 MOD 的全部分组、各组预设、默认项、变身规则及材质/子网格匹配资料。面板编辑后自动保存；“另存预设文件”可使用中文名称。“启用变身”总开关是本地偏好，只保存在主配置中，不随 `.wdp` 分享。

给 pl105、pl106 安装同款 MOD 后：

1. 在 pl105 制作分组、预设与变身规则，保存为如 `黎明巫女.wdp`。
2. 保持“换装自动识别”开启，切换到 pl106 并等待模型加载。
3. 插件按材质识别文件，将分组成员、显隐规则及变身目标重新绑定到 pl106 的分组和预设。

也可通过“手动查找”指定文件，或点击“自动查找”立即重新识别。文件可以用独立 MOD 名供多套装备共用；也可以命名为 `pl106_0000.wdp`，材质命中数相同时优先装备同名文件。没有可用运行时材质时，允许装备同名文件匹配。

识别会比较各部位的材质、分组成员及全部预设。子网格规则会按材质、几何资料和序号重绑定；无法确定的内容会跳过并提示。安装完全不同的模型后，应检查实际效果。

手动载入会替换当前装备的分组、预设和变身规则，替换前自动备份到 `WorldDiff/Backups`。已有文件关联的装备会继续使用关联文件。想切换文件时，使用手动或自动查找；自行配置且未关联文件的装备不会被后台识别覆盖。

将预设作为 MOD 一部分发布时，提供对应 `.wdp`，放在 `nativePC/plugins/WorldDiff/Presets/`。使用者需要安装 1.0.7 或后续兼容版本；不必附带自己的主配置和备份目录。

## 文件与恢复

| 文件或目录 | 作用 |
| --- | --- |
| `nativePC/plugins/WorldDiff.dll` | 游戏内插件 |
| `nativePC/plugins/WorldDiff/WorldDiff107.cfg` | 当前设置、装备关联、分组、预设与变身规则 |
| `nativePC/plugins/WorldDiff/Presets/*.wdp` | 可分享、可跨装备识别的 MOD 预设文件 |
| `nativePC/plugins/WorldDiff/Backups` | 载入替换前的配置备份 |
| `nativePC/plugins/WorldDiff104.log` | 运行日志；文件名沿用现有诊断入口 |

安装脚本的升级前备份位于游戏根目录 `WorldDiff-backups/before-1.0.7-*`。回退时先退出游戏，再还原对应 DLL 与数据备份。

支持的游戏版本为 Steam 15.23.00。插件不修改 MOD 文件和原始 Group_ID；游戏显隐函数签名不匹配时不安装显隐钩子。原生输入法候选窗在独占全屏下尚未验证，候选窗不可见时可使用无边框窗口。
