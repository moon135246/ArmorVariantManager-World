# 差分管理器 · 世界内置版 1.0.8

插件随游戏启动，F9 开关面板，不需要连接游戏。此版把变身改成预先设好状态的面板：在收刀、拔刀、红刃等状态下面直接选择分组和预设，无需给规则命名或自行搭建条件。

## 安装与升级

需要 Stracker's Loader。退出游戏后将 `nativePC` 合并到游戏根目录，或运行“安装到游戏.cmd”。安装脚本会备份旧 DLL 和 WorldDiff 数据目录。

1.0.8 使用 `nativePC/plugins/WorldDiff/WorldDiff108.cfg`。首次启动依次迁移 107、104、103 配置，保留原文件。旧版已经设置的分组、预设和变身绑定会保留；同类条件会显示在对应状态下面。

新保存的 `.wdp` 使用 108 格式，旧插件无法读取。回退时请同时恢复升级前的 DLL、主配置和 `.wdp` 备份。安装脚本的备份位于游戏根目录 `WorldDiff-backups/before-1.0.8-*`。

## 最快的使用方法

以拔刀隐藏头发、收刀显示头发为例：

1. 在“头发”分组保存“显示头发”“隐藏头发”两个预设。
2. 打开“变身与条件”，勾选“启用变身”。
3. 使用“选择模式”，条件类型选“收刀与拔刀”。
4. 在预先列出的“收刀”下面，选头发分组和显示头发预设。
5. 在“拔刀”下面，选头发分组和隐藏头发预设。

选择后自动保存，关闭面板也会继续生效。一种状态可点击“添加目标分组”，同时切换多个分组。

预设选“不切换”表示该绑定不接管基础状态。条件退出后恢复手动选择的基础预设；变身不会自动改写启动默认项。全局分组继续叠加隐藏。

## 选择模式与并行模式

“选择模式”只运行下拉框里选中的一类条件。切换条件类型会保留以前配置的绑定，切回来即可继续使用。

“并行模式”允许同时勾选收拔刀、太刀、血量等多类条件，各类有独立优先级。数字越小越优先；控制不同分组的条件可同时生效。同一分组有冲突时由优先级决定。

“启用变身”、模式、各类优先级和绑定属于当前装备的配置，会随预设文件保存。游戏里的“暂停并恢复”和 Ctrl+F9 仍可暂停全部差分控制。

## 已设好的五类条件

| 类别 | 可直接选择的状态 |
| --- | --- |
| 收刀与拔刀 | 收刀、拔刀 |
| 太刀气刃等级 | 无刃、白刃、黄刃、红刃 |
| 双刀状态 | 普通、鬼人化、鬼人强化 |
| 操虫棍三灯 | 三灯齐全、无精华、红、白、橙，以及红白、红橙、白橙组合 |
| 猎人血量 | 归零、0–25%、25–50%、50–75%、75–100%，以及 ≤25/50/75% 的保持状态 |

双刀以鬼人化状态优先；退出鬼人化后，再根据强化标志使用鬼人强化或普通项，避免两个状态争用同一分组。

操虫棍按三种精华的实际剩余计时判断。两种颜色同时亮时使用对应组合，三灯齐全时使用三灯项。猎虫的气／力强化属于另一种状态，和精华三灯分开。

血量区间包含上限、排除下限；例如 25–50% 表示 `25% < 血量 ≤ 50%`。点击“添加血量节点”可设置自己的上下限与保持选项。同优先级下，命中的血量上限越低越优先。

保持状态仅在正血量触发，回血后仍保持；血量归零、切图、角色变化、换武器、关闭变身、重载或调整配置时复位。“复位保持状态”可以手动复位；当前条件仍满足时会再次触发。

旧版的“白刃及以上”等补充条件会保留在对应类别的“其他已保存的状态”中。旧版动作 LMT、武器种类等配置保留在折叠的“以前版本的其他条件”中，迁移后默认暂停，可按需要开启。

## 分组与预设文件

普通分组独占材质，主列表管理未分组的材质。全局分组允许重叠，并在最后叠加隐藏。每个分组有独立预设和启动默认项。

`nativePC/plugins/WorldDiff/Presets/*.wdp` 包含 MOD 的全部分组、预设、默认项、变身设置和匹配资料。作为 MOD 一部分发布时，只需提供对应 `.wdp` 并说明需要 1.0.8；不必附带自己的主配置或备份。

给 pl105 和 pl106 安装同款 MOD 后，可将预设另存为独立 MOD 名，通过自动或手动查找在另一套装备载入。材质、子网格、变身目标分组和预设会重新关联；模式与各类优先级一同迁移。

材质命中数相同时优先装备同名文件，如 `pl106_0000.wdp`。手动载入前自动备份到 `WorldDiff/Backups`。已有装备关联的文件会继续使用，切换文件可使用手动或自动查找。

## 输入与恢复

- F9 打开或关闭，Esc 关闭面板；关闭后游戏恢复接收输入。
- 默认按子网格，名称后不显示编号；材质悬停不弹技术信息框。
- 名称使用原生 Unicode 输入框，可输入中文；回车完成，Esc 取消。
- 分组与预设列表支持拖动排序；拖动提示点击 x 后永久隐藏。
- 变身接管当前组时，可点击“暂停变身并编辑”调整基础显隐。
- Ctrl+F9 暂停全部控制并恢复游戏显隐，已保存预设继续保留。

支持 Steam 15.23.00（build 421810）。插件不改写 MOD 文件和原始 Group_ID；日志沿用 `nativePC/plugins/WorldDiff104.log`。独占全屏下的输入法候选窗未全面验证，可使用无边框窗口。
