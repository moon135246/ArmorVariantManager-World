# 差分管理器 · 世界内置版 1.1.5

插件随游戏启动，F9 开关面板，不需要连接游戏。此版把变身改成预先设好状态的面板：在收刀、拔刀、红刃等状态下面直接选择分组和预设，无需给规则命名或自行搭建条件。

1.1.5 默认直接使用对应 MRL3 文件的材质记录顺序排列“按子网格”和“按材质”列表。按材质名哈希对应 MOD3 的实际网格，避免把网格表序号、材质槽序号和 MRL3 记录序号混为一谈。同一材质对应多个网格时，子网格视图仍分别列出；同材质内按原网格索引保持稳定。此功能不需要 Blender 工程或作者额外提供顺序表。

缺少可读的同名 MRL3、材质没有对应记录时，使用 MOD3 材质槽次序作为后备；缺少散装文件的打包资源无法承诺还原 MRL3 记录顺序。1.1.4 的 `.meshorder` 不再参与新版默认排序，已有文件可保留供旧版回退。

## 手动网格顺序与备注

- 在“按子网格”视图拖动网格名称，上半行表示插到该网格前，下半行表示插到它后。支持拖到最后一行之后；调整范围为当前模型。
- 右键网格名称选择“编辑备注”。备注显示在原材质名称旁，可用中文，留空或右键“清除备注”可恢复原显示。搜索框可以搜索网格备注。
- “恢复材质顺序”清除当前模型的手动顺序，同时保留备注。
- 手动顺序与备注在同一装备模型的各分组、预设之间共用，并自动保存；显隐目标仍使用原网格身份。调整显示顺序、填写备注不会改变已有显隐或变身绑定，也不会重命名 MOD 文件里的材质。
- 多个网格共用一个材质时，仍可分别备注和排序。模型签名或材质身份不匹配的旧记录不直接套用，避免给变更后的网格贴错备注。
- 另存或分享 WDP 时，手动顺序与备注一起保存；载入同款 MOD 的其他装备编号时使用现有材质、几何与网格内次序映射重新关联。无法确定的映射会跳过并提示。

1.1.3 在装备选择框、下拉列表、手动查找窗口和载入／匹配提示中，使用“正式中文名(模型编号)”显示，例如 `【冰狼】服装(pl105_0000)`、`【浴场】服装(pl106_0000)`、`【精英·巨蜂】服装(pl007_0001)`。名称来自游戏当前简体中文防具系列文本，覆盖所提供资料中的 274 个编号，已内置于 DLL，不需要另外安装名称文件。

独立编号保留阿尔法、贝塔、伽马和“精英·”名称。同一模型被多套装备共用时优先使用游戏的外观装备系列名；悬停装备项可查看共用系列。男女专用系列根据已加载的模型目录选择名称。较长名称可悬停查看，资料未收录的模型仍显示原编号。主配置、预设文件名与匹配关系继续使用原始模型编号。

1.1.3 调整顶部布局：版本说明只保留在窗口标题栏；“启用”和“暂停并恢复”与装备及显隐状态放在同一行。右侧拖动提示使用信息图标、浅蓝文字、圆角边框及独立关闭叉，内容为“提示：可拖动左侧的【分组列表】和【预设列表】调整顺序。”，窄窗口自动换行。

提示框按文字实际宽度收紧，并靠右放置；关闭叉与文字之间只保留必要间距，不再拉满整列。窗口变窄时按可用宽度换行。

## 安装与升级

需要 Stracker's Loader。退出游戏后将 `nativePC` 合并到游戏根目录，或运行“安装到游戏.cmd”。安装脚本会备份旧 DLL 和 WorldDiff 数据目录。

1.1.5 使用 `nativePC/plugins/WorldDiff/WorldDiff115.cfg` 和 WDP 115 格式保存网格备注及手动顺序。首次启动自动读取既有 WorldDiff110.cfg；更早版本继续依次读取 109、108、107、104、103。原配置保留，既有分组、预设、默认项及变身规则仍可读取。

新保存的 WDP 115 需要差分管理器 1.1.5 或更新版本，旧 WDP 110 可以继续载入。回退至 1.1.4 或更早插件时，恢复升级前 DLL、配置与 WDP；不能让旧插件直接读取新版 WDP。安装脚本备份位于游戏根目录 `WorldDiff-backups/before-1.1.5-*`。

## 最快的使用方法

以拔刀隐藏头发、收刀显示头发为例：

1. 在“头发”分组保存“显示头发”“隐藏头发”两个预设。
2. 打开“变身与条件”，勾选“启用变身”。
3. 使用“选择模式”，条件类型选“收刀与拔刀”。
4. 在预先列出的“收刀”下面，选头发分组和显示头发预设。
5. 在“拔刀”下面，选头发分组和隐藏头发预设。

选择后自动保存，关闭面板也会继续生效。一种状态可点击“添加目标分组”，同时切换多个分组。

预设选“不切换”表示该绑定不接管基础状态。条件退出后恢复手动选择的基础预设；变身不会自动改写启动默认项。全局分组继续叠加隐藏。

## 选择模式与并行模式

“选择模式”只运行下拉框里选中的一类条件。切换条件类型会保留以前配置的绑定，切回来即可继续使用。

“并行模式”允许同时勾选收拔刀、太刀、血量等多类条件，各类有独立优先级。数字越小越优先；控制不同分组的条件可同时生效。同一分组有冲突时由优先级决定。

“启用变身”、模式、各类优先级和绑定属于当前装备的配置，会随预设文件保存。游戏里的“暂停并恢复”和 Ctrl+F9 仍可暂停全部差分控制。

## 九类变身条件

| 类别 | 可直接选择的状态 |
| --- | --- |
| 收刀与拔刀 | 收刀、拔刀 |
| 太刀气刃等级 | 无刃、白刃、黄刃、红刃 |
| 双刀状态 | 普通、鬼人化、鬼人强化 |
| 操虫棍灯数 | 无精华、一灯、二灯、三灯齐全 |
| 猎人血量 | 点击“添加血量节点”设置需要的区间 |
| 弓蓄力等级 | 未蓄力、一蓄、二蓄、三蓄 |
| 大锤蓄力等级 | 未蓄力、一段、二段、三段 |
| 盾斧形态 | 剑／斧基础形态、剑红盾、剑红剑、剑红盾＋红剑、斧红斧、三红齐全 |
| 斩斧形态 | 斧／剑基础形态、强化斧、高出力剑 |

双刀以鬼人化状态优先；退出鬼人化后，再根据强化标志使用鬼人强化或普通项，避免两个状态争用同一分组。

操虫棍按三种精华的实际剩余计时统计灯数，同样是一灯或二灯时不再区分颜色。猎虫的气／力强化不会计入灯数。

弓显示“未蓄力、一蓄、二蓄、三蓄”，结束蓄力后回到未蓄力。旧版四个状态的绑定保持原位，只修正描述。弓、大锤、盾斧和斩斧条件只在装备相应武器时生效。

盾斧的三种强化同时存在时使用“三红齐全”项，剑／斧形态均可触发，优先于其他强化组合。其他情况下，剑形态按红盾与红剑组合切换，斧形态有红斧项。斩斧在斧形态检查强化斧，在剑形态检查高出力；两种强化可以同时存在。

强化项有预设绑定时，优先于同优先级的基础形态绑定；未指定预设的目标分组继续使用对应基础形态的绑定。基础形态也未绑定时，使用手动选择的基础预设。旧版剑／斧预设因此可继续使用，再按需要设置强化项。

血量页不再自动列出固定区间，只显示“添加血量节点”和已经保存的节点。可设置上下限、是否包含下限及保持选项。同优先级下，命中的血量上限越低越优先。

每个节点标题右侧都有“删除”按钮，收起节点后也可删除。删除会解除该节点的变身接管及保存的绑定，分组和预设仍然保留；保存或重启后，已删除节点不会自动重新生成。删除分组或预设时，只清理血量节点中对应的绑定，节点本身保留，可重新选择目标。

保持状态仅在正血量触发，回血后仍保持；血量归零、切图、角色变化、换武器、关闭变身、重载或调整配置时复位。“复位保持状态”可以手动复位；当前条件仍满足时会再次触发。

旧版的“白刃及以上”等同类补充条件仍显示在对应类别的“其他已保存的状态”中。已移除“以前版本的其他条件”入口。并行模式的九类条件在独立区域内滚动，下面的状态列表保留可用空间。

## 分组与预设文件

普通分组独占材质，主列表管理未分组的材质。全局分组允许重叠，并在最后叠加隐藏。每个分组有独立预设和启动默认项。

`nativePC/plugins/WorldDiff/Presets/*.wdp` 包含 MOD 的全部分组、预设、默认项、变身设置和匹配资料。作为 MOD 一部分发布时，只需提供对应 `.wdp` 并说明需要 1.1.5；不必附带自己的主配置或备份。

给 pl105 和 pl106 安装同款 MOD 后，可将预设另存为独立 MOD 名，通过自动或手动查找在另一套装备载入。材质、子网格、变身目标分组和预设会重新关联；模式与各类优先级一同迁移。

材质命中数相同时优先装备同名文件，如 `pl106_0000.wdp`。手动载入前自动备份到 `WorldDiff/Backups`。已有装备关联的文件会继续使用，切换文件可使用手动或自动查找。

## 输入与恢复

- F9 打开或关闭，Esc 关闭面板；关闭后游戏恢复接收输入。
- 默认按子网格，名称后不显示编号；材质悬停不弹技术信息框。
- 名称使用原生 Unicode 输入框，可输入中文；回车完成，Esc 取消。
- 分组与预设列表支持拖动排序；拖动提示点击右侧关闭叉后永久隐藏，沿用已保存的隐藏设置。
- 变身接管当前组时，可点击“暂停变身并编辑”调整基础显隐。
- Ctrl+F9 暂停全部控制并恢复游戏显隐，已保存预设继续保留。

支持 Steam 15.23.00（build 421810）。插件不改写 MOD 文件和原始 Group_ID；日志沿用 `nativePC/plugins/WorldDiff104.log`。独占全屏下的输入法候选窗未全面验证，可使用无边框窗口。
