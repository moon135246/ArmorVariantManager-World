# 怪物猎人：世界／冰原 - 差分管理器

这是一个针对在游戏内管理防具 MOD 的外观差分，将多个部位的显示／隐藏保存成预设，再通过分组、变身条件或快捷键切换搭配的工具。

世界版沿用 ArmorVariantManager 系列名称，针对 MT Framework 独立实现原生 DLL 后端。荒野／崛起版见 [ArmorVariantManager](https://github.com/Monkeysama/ArmorVariantManager)；变身条件参考项目见下方致谢。

已验证环境：Windows x64、Steam 15.23.00（build 421810）、Stracker's Loader、DX12。

## 使用方法（MOD 用户）

### 1. 安装

1. 安装适用于当前游戏版本的 Stracker's Loader。
2. 从 [Releases](https://github.com/moon135246/ArmorVariantManager-World/releases/latest) 下载安装包 `ArmorVariantManager-World-v1.2.2.zip`，正常退出游戏后解压。
3. 将包内 `nativePC` 合并到游戏根目录，即 `MonsterHunterWorld.exe` 所在目录。覆盖前备份已有插件和 `WorldDiff` 数据目录；保留自己的预设、模板、设置及手动更新日志。
4. 也可以在安装包目录打开 PowerShell，执行 `& '.\安装到游戏.ps1' -GamePath '你的游戏根目录'`。脚本会先备份已有 DLL 和数据；默认路径未必适合本机，请明确传入自己的路径。
5. 从 Steam 启动游戏，使用 DX12。

插件路径为 `nativePC/plugins/WorldDiff.dll`。GitHub 的自动生成附件 **Source code (zip / tar.gz)** 是源码，不是可以直接安装的插件包。

### 2. 切换预设

- **F9** 打开或关闭面板；**Ctrl+F9** 暂停控制并恢复游戏显隐。
- 面板跟随本地主角当前实际显示的装备，包括幻化；选择分组后点击其中的预设即可应用。
- 没有对应预设时，先把分享的 `.wdp` 模板放入 `WorldDiff/Templates`，再通过“手动查找”或“自动查找”匹配当前装备。
- 日常编辑保存在 `WorldDiff/Presets/装备编号.wdp`，与分享模板分开；换装后读取新装备的文件。

### 3. 预设快捷键

先保存分组预设，再进入“预设快捷键”新建方案，为每个需要控制的分组选一个已有预设，录制按键或 Ctrl／Shift／Alt 组合键。

关闭面板后按一次快捷键，即可应用整套组合；未列入的分组保持原样。变身与预设快捷键的总开关只能开启一个，需要先关闭另一页的总开关。

### 4. 常见问题

- **换了装备，原预设没出现？** 面板只处理当前穿着的装备。更改 MOD 或模型后，需要重新匹配当前文件或查找模板。
- **保存的预设在哪里？** 位于 `nativePC/plugins/WorldDiff/Presets`；分享时使用“导出模板”，导出的文件位于 `Templates`。
- **怎样恢复旧内容？** 在“设置”中使用预设备份恢复功能。每份文件保留最近五份不同内容，升级安装另有整目录备份。
- **联机时会修改队友的文件吗？** 效果仅作用于本机画面。队友只读匹配本机已有预设，面板和保存目标始终属于本地主角。
- **快捷键没有触发？** 检查两项互斥开关、方案启用状态及当前装备是否匹配。面板打开、输入文字、失焦、换装过渡、存档预览或总暂停时，不执行实体快捷键。

完整操作和旧数据迁移见 [使用说明](发布/使用说明.md)。

## 使用方法（MOD 作者）

### 材质和子网格

在“部位与材质”中选择控制方式，通过勾选调整显隐。默认网格列表优先使用可读取的 MRL3 材质记录顺序；可手动拖动排序，并右键添加中文备注。插件不改写 MOD3／MRL3 文件。

### 分组和预设

普通分组管理独立部位，主列表保留未分组内容；全局组可以与其他分组重叠，叠加隐藏规则。调整当前组的显隐后保存预设，可设置默认项，分组及预设支持拖动排序。

### 变身与条件

将已有预设分配给角色状态条件，实现临时切换与条件结束后的回退，支持选择／并行模式。原始基础预设定义不会被变身结果改写。

### 分享模板

完成配置后使用“导出模板”，分享生成的 `.wdp` 文件。用户将模板放入 `Templates` 并匹配装备，后续编辑保存在自己的装备编号文件中，不会写回分享模板。

重新导出模型后需要核对匹配结果。缺少 MRL3、网格重新拓扑或几何数据无法区分时，不能保证自动还原原工程顺序或网格身份。
