# 模块说明

| 模块 | 职责 |
|---|---|
| Runtime / RenderPolicy | 绘制目标校验、按实例应用显隐、发布只读渲染策略 |
| VisibilityQueryHook | 在共享查询的直接调用及虚表分发处协调变身插件优先级，区分插件接管与游戏透传 |
| Overlay / Dx12Backend / NativeInput | 游戏内界面、图形后端、原生中文输入与按键采样 |
| Panel / TransformPanel / HotkeyPanel / ReorderList | 面板、变身、预设快捷键和拖动交互 |
| State / Storage / Profiles / VariantMapping | 分组预设、当前外观跟随、文件迁移与备份、模板映射 |
| ModelCatalog | MOD3／MRL3 结构读取、材质及网格身份 |
| PlayerState | 本地角色、存档预览、玩家容器、状态及文字输入识别 |
| Multiplayer | 队友实例生命周期、只读预设匹配和独立条件计算 |
| Transform / TransformSlots | 条件求值及临时预设接管 |
| ArmorNames / ArmorNamesData | 装备编号与中文名称索引 |
| UpdateNotes | 手动更新日志的有界读取 |

本地面板始终跟随本地主角；队友不会成为编辑与保存目标。角色身份不能由玩家槽位推断。共享模型资源的角色仍使用独立实例显隐策略。

快捷键方案属于当前装备 WDP，变身与快捷键总开关保存在 Settings，二者互斥。Settings 129 可读 117／121／122／123／124／128，新增默认开启的差分优先级，保存默认双键或自定义单键。WDP 含待匹配目标时使用 128，否则沿用 122，并兼容已有支持格式。材质名称优先逐对象映射，同名多网格无法唯一对应时保留待匹配规则。仅安装不提前重写原配置，相关保存才升级格式，回退需要使用备份。

显隐不再覆盖第三方插件共用查询函数的入口；在受支持的直接 CALL 点及指向查询入口的静态虚表／函数引用处执行当前查询链，保持对象的虚表指针身份不变，经过原函数正文的线程局部标记区分透传和提前返回，再在调用者淡出判断前应用优先级。策略快照同时发布启用状态、优先级、材质、Group ID 和隐藏掩码，强制显示仍须通过实例、资源、网格、材质和路径校验。见 [变身插件兼容说明](VISUAL_CONTROLLER_COMPATIBILITY.md)。

内存偏移和结构依赖已验证的游戏版本，更新游戏后需要重新核对。公开源码没有附带可独立替代游戏或 MOD 的资源。
