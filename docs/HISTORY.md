# 历史版本

2026-11-07：主分支更新至 **1.3.1**，发布对应源码标签及直装包；包含 MHWSS 兼容性修复与更新日志折行优化。

截至 1.3.1，仓库收录 **28 个源码版本标签**：1.0.2～1.2.7，以及 1.3.0、1.3.1。不收录 1.0.0、1.0.1 和“初次尝试”目录；本地开发期间的 1.2.8 未单独建立正式发布标签。

当前主分支包含 **1.3.1 源码及发布资料**。最初的 1.0.2～1.2.2 共 21 份现存源码快照按版本导入为归档提交，并建立对应的版本标签。这些提交的日期是归档日期，不代表原开发时间；后续版本在此基础上继续提交。

快照从现存版本目录按允许清单提取，没有虚构原开发日期或原 Git 提交历史。旧快照没有逐版重新编译和实机验收，旧版不推荐覆盖当前版本使用。

GitHub 已发布 **8 个正式版安装包**：1.2.2、1.2.3、1.2.4、1.2.5、1.2.6、1.2.7、1.3.0 和 1.3.1，最新正式版为 1.3.1。安装包与 SHA256 校验文件位于对应版本的 Release；GitHub 自动生成的源码压缩包不是插件安装包。

这些正式版安装包均采用直装结构：将 `nativePC` 合并到游戏根目录。第三方说明位于 `nativePC/plugins/WorldDiff/THIRD_PARTY_NOTICES.md`，许可原文位于同目录的 `licenses/`。许可目录调整保留了各版本原有的 DLL、更新日志和许可原文；源码标签不因仅调整附件结构而移动。

原始运行日志、个人预设、测试捕获、完整游戏资源以及 MOD 模型、贴图未随仓库分发。装备中文名称索引所用的名称与兼容性信息另有来源说明，见第三方署名。

早期候选安装包只保留在本地。1.0.3 原发布目录只有 DLL 和运行日志；整理候选包时排除了日志，并补充对应的第三方许可证及手动安装说明。候选包从各版发布目录重新整理，不冒充原 ZIP 的字节副本；插件二进制保持原字节并记录哈希。

历史源码和合成测试夹具可能提及更早版本名称，这是原文字及兼容性数据，不代表收录或发布那些版本。
