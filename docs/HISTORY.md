# 历史版本

本次整理范围为 **1.0.2～1.2.2，共21个版本**。不收录1.0.0、1.0.1和“初次尝试”目录。

当前开发目录以1.2.2为基线。1.0.2～1.2.2的现存源码快照按版本导入为归档提交，并建立对应的v版本号标签；这些提交的日期是归档日期，不代表原开发时间。主分支只保留最新文件状态。

快照从现存版本目录按允许清单提取，没有虚构原开发日期或原 Git 提交历史。旧快照没有逐版重新编译和实机验收，旧版不推荐覆盖当前版本使用。

首次安装包Release为1.2.2，旧版候选安装包先保留本地。后续若发布历史Release，应使用对应源码标签并附上相同版本的安装包。原始运行日志、预设、测试捕获、游戏及MOD资源均未收录。

1.0.3原发布目录只有DLL和运行日志；日志已排除，候选包补充了对应第三方许可证及手动安装说明。历史安装包是从各版发布目录重新整理的候选包，不冒充原ZIP的字节副本；插件二进制保持原字节并记录哈希。

保留的历史默认日志与测试夹具可能提及更早版本名称，这是原文字及兼容性数据，不代表收录或发布那些版本。
